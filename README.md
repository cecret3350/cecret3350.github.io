# Zixuan Chen — Academic Homepage

一个无需构建工具的响应式学术个人主页，参考 Hanwen Jiang 的个人网站信息结构重新设计。

## 本地预览

直接打开 `index.html`，或在当前目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 修改内容

- 个人简介、教育背景、研究经历、论文、服务与荣誉：编辑 `index.html`
- 颜色、排版与响应式布局：编辑 `styles.css`
- 论文筛选、移动导航与滚动动画：编辑 `script.js`
- 个人照片文件为 `photo.jpeg`；替换同名文件即可更新头像

当前学术内容根据 `chenzixuan_cv.pdf` 更新。
